# Pretty Log JSON

**Pretty Log JSON** — это плагин для IntelliJ IDEA, который форматирует JSON-логи в удобочитаемый вид прямо в редакторе. Он автоматически находит JSON-объекты в строках (в том числе с префиксами `/entrypoint.sh:` или временными метками) и заменяет их на отформатированный JSON с отступами.

## Возможности

- Форматирование JSON-строк, даже если они находятся внутри лог-сообщений.
- Поддержка префиксов (`/entrypoint.sh:`, временные метки и т.д.) — JSON извлекается автоматически.
- Работа с выделенным фрагментом текста или со всем документом.
- Игнорирование некорректного JSON — такие строки остаются неизменными.
- Обработка JSON-массивов.
